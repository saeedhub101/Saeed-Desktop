# Saeed: Roadmap

Do one phase at a time. A phase is done only when its acceptance checklist is fully ticked.

| Phase | Name | Outcome |
|---|---|---|
| 1 | Shell and 3D window | Tray app, transparent character window shows a GLB, hide/show by destroy, quit from tray only |
| 2 | Rig tools | Skeleton viewer, Bone Mapper, Rest Pose Editor, Axis Wizard, profiles, test poses |
| 3 | Character Engine | Intent API, Behavior Layer, procedural motions, idle life cycle, face, speech bubble |
| 4 | Conversation and Brain | SQLite session, chat window, one LLM provider, Brain Router with local intents |
| 5 | Voice | Mic with VAD, STT slot, TTS slot, mute, lip sync, unified history |
| 6 | Service Manager | Full create/destroy lifecycle, idle timers, Diagnostics tab |
| 7 | Tools and Permissions | System/files/input/screen tools, Permission Manager, Stop-all hotkey |
| 8 | Plugins | Manifest, process host, Office/PDF/OCR, Whisper plugins |
| 9 | Realtime | Realtime provider adapters, shared transcript |
| 10 | Customization | Outfits, accessories, event props, animation packs, character store |
